# Chishty Productions | Video Editing

A responsive video-editing portfolio featuring real work samples, on-demand video players, category filters, and a project enquiry flow.

[Live portfolio](https://adilchisty963.systeme.io/630c665e)

## Run and Build

Open `index.html`, or run `node serve.cjs` for a local preview. Regenerate the standalone website and Carrd embed with:

```sh
node build.mjs
```

No package installation is required. The editable source is `body.html`, `portfolio.css`, and `portfolio.js`. The Chishty Productions logo and branded cover fallbacks are embedded in the markup.

## Publishing

- `index.html`: standalone website.
- `carrd-embed.html`: optional custom-code embed.
- `systeme-upgrade.html`: the live Systeme.io footer integration, preserving the existing native enquiry form.

The standalone build directs enquiries to the existing Systeme.io form. The Systeme.io integration depends on that platform's native form and existing page configuration. It is provided separately and is not regenerated by `build.mjs`.

Video players load only after Play is selected. Google Drive controls video access and playback availability. Samples, logo, and branding belong to Adil Amin Chishty / Chishty Productions.
